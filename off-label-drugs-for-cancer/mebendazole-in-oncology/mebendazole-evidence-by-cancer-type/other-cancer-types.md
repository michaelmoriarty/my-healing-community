# Other Cancer Types

Mebendazole's pathway relevance extends across multiple cancers beyond the strongest ovarian, colorectal, breast, brain, and lung examples.

### Additional evidence areas

* **Melanoma** — ERK / MAPK-heavy biology makes this an especially interesting future direction
* **Pancreatic cancer** — pathway logic suggests relevance, though the current note set is still broad rather than cancer-page-specific
* **Other ERK-driven tumours** — including hepatic, oral, and some leukemic settings

### Practical interpretation

This page acts as a holding space for additional cancers where the biological rationale is strong, but the current topic notes are not yet deep enough to justify full standalone pages.
