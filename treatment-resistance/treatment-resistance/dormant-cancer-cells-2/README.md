# Dormant Cancer Cells

Dormancy is a cross-cancer issue.

It matters when visible disease is tiny, when scans suggest residual disease, or when recurrence risk stays present long after apparently good treatment response.

Use this section for questions about dormant cells, reactivation triggers, and the difference between trying to kill every visible spot and trying to control the biology that lets residual cells survive.

For the autophagy-survival side of dormancy, see [Autophagy — Cancer's Escape Route](../autophagy-cancers-escape-route/) and [The Early Window — Part One](../autophagy-cancers-escape-route/the-early-window-part-one.md).

For the parallel escape route through therapy-induced senescence, see [Senescence — The Second Escape Route](../senescence-the-second-escape-route/).
