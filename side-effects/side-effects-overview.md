# Side Effects Overview

This section gathers side-effect, symptom-support, and recovery topics that cut across cancer types and treatments.

### How to use this section

1. Start with the symptom page that best matches the problem.
2. Use the A–Z below for deep dives and discussion links.
3. Escalate red-flag symptoms early rather than waiting.
