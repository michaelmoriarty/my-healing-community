# Accessing Testing Without a Referral

If you want testing without waiting for a referral, look for three things:

* quantified results with reference ranges
* a clinical-grade laboratory using ICP-MS or equivalent
* a clear sample type that matches the question you are asking

Availability and pricing change.

Always verify current test format, lab method, and shipping rules before ordering.

### Australia

* [i-screen](https://www.i-screen.com.au/tests/toxic-metals-urine-test)\
  Direct-access urine and whole-blood heavy-metal options through NATA-accredited labs.
* [Bloody Good / NutriPATH](https://bloodygood.com.au/products/essential-mineral-and-heavy-metal-analysis-urine-kit)\
  Direct-access urine kit linked to NutriPATH testing.
* [iMedical](https://imedical.com.au/order/blood-tests/metals-private-blood-tests)\
  Private blood panel access for common metals through collection-centre partners.

### United Kingdom

* [Clinical Revelation / Doctor's Data](https://clinicalrevelation.co.uk/products/toxic-heavy-metals--essential)\
  Home urine testing processed through Doctor's Data.
* [Nordic Labs](https://nordiclabs.com/testdetail/urine-toxic-metals-single-or-timed-post/2746)\
  Direct access to urine toxic-metal options, including timed collections.
* [Private Blood Tests London](https://www.privatebloodtestslondon.co.uk/blood-test/mineral-screen-and-industrial-heavy-metal-screen-trace-metals)\
  Self-referral blood-based heavy-metal testing.
* [Maple Leaf Pharmacy](https://www.mapleleafpharmacy.co.uk/private-blood-test/toxicology-heavy-metals/)\
  London-based toxicology blood-test access.
* [AlphaBiolabs](https://www.alphabiolabs.co.uk/workplace-testing-services/trace-metal-testing/)\
  Trace-metals blood-panel option through a UK lab.

### Canada

* [Blood Tests Canada](https://bloodtestscanada.com/collections/heavy-metal-analysis)\
  Heavy-metal blood panels via Dynacare, ordered online with collection-centre follow-through.
* [Osumex HMT kits](https://osumex.com/)\
  Preliminary home screen only. This is not the same as clinical-grade quantitative testing.

### United States

* [myLAB Box](https://www.mylabbox.com/product/heavy-metals-home-screening-test/)\
  At-home screening for common heavy metals.
* [MyMedLab / Doctor's Data](https://www.mymedlab.com/no-lab-visit-tests/urine-toxic-metals-doctor-s-data)\
  Direct-access 24-hour urine toxic-metals testing through Doctor's Data.
* [Vibrant Wellness](https://vibrant-wellness.com/tests/toxins/heavy-metals)\
  Broad blood or urine panel through provider-linked ordering pathways.
* [Doctor's Data test menu](https://www.doctorsdata.com/Toxic-and-Essential-Elements)\
  Useful reference point for panel formats and sample-type options.

### How to choose between them

Use blood when you want recent or circulating levels.

Use 24-hour urine when you want excretion data.

Use copper plus ceruloplasmin when you want the most practical first step tied to active cancer biology.

### Practical takeaway

No-referral access is now possible in several countries.

The real task is choosing the right sample type and not mistaking screening convenience for clinical usefulness.
