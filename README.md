### How to use this site

1. Start with the section that best matches the kind of question you have.
2. Use overview pages or directory pages first.
3. Move into deeper pages only when you need more detail.
4. Use the support and thriving sections alongside the evidence sections, not instead of them.

### What this site is for

This site exists to help people:

* understand complex treatment and supplement questions more clearly
* find practical support that does not feel superficial
* locate structured, evidence-aware resources without getting lost
* hold together science, lived experience, and the deeper work of staying alive inside a difficult reality
