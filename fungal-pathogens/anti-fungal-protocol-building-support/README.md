# 🍄 Anti-fungal Protocol Building Support

Fungal pathogen clearance often needs more than one lever.

This guide uses a layered design that combines immune calming, fungal weakening, biofilm disruption, direct antifungal pressure, safer cleanup, and structured monitoring.

{% hint style="warning" %}
This content is educational only. It is not medical advice. Prescription antifungals, liver monitoring, blood testing, and protocol customisation need practitioner oversight.
{% endhint %}

### What this protocol is trying to do

* turn down the chronic danger signal
* weaken fungal virulence
* break down biofilm structure
* apply direct kill where appropriate
* reduce die-off burden
* support tissue recovery

### Key safety notes

* discuss supplements, prescriptions, and interactions with your clinician
* use proper liver and safety monitoring
* report adverse effects early
* do not self-diagnose or self-escalate
* individual responses vary

### Key principles

* **Multi-layered approach:** each component has a different job
* **Timing matters:** spacing reduces interference
* **Medical supervision matters:** this is not a DIY drug protocol
* **Pace matters:** adjust to tolerance and context
* **Foundation matters:** hydration, nutrition, rest, stress, and mould remediation all change results

### Work in progress notes

* compatibility questions still being explored for TUDCA, milk thistle, and chlorella

### Bottom line

This is a journey, not a sprint.

The protocol works best when it is sequenced, monitored, and matched to the fungal pattern, the exposure context, and the person’s tolerance.
