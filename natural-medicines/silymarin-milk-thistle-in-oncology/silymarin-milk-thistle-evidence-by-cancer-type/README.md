# Silymarin / Milk Thistle Evidence by Cancer Type

Silymarin is extracted from the seeds of **Milk Thistle** (_Silybum marianum_). When you see Silymarin or Silibinin in oncology research, this is still the Milk Thistle topic.

This section groups the cancer-type evidence into focused subpages.

The literature ranges from extensive preclinical work to selected human trials, with the strongest clinical-supportive evidence often centred on liver protection and treatment tolerability.
