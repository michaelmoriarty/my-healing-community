# Polydatin Evidence by Cancer Type

This section groups the polydatin oncology evidence into individual cancer-type pages.

That structure keeps each cancer page easier to navigate, keeps references attached to the relevant discussion, and makes future updates much easier.

Be sure to read the Polydatin [Safety & Interactions](../safety-and-interactions.md) page as well, especially the cautions for G6PD-related and HER2-positive breast cancer.
